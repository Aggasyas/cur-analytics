# Аналитика ЦУР

Аналитика по обращениям жителей из одной накопительной выгрузки с начала года →
анонимизированные HTML-страницы (только цифры и подтемы, без текстов обращений) →
публикация на GitHub Pages → ссылка в чат ЦУР через Telegram-бота.

**Рабочий файл** — накопительная выгрузка обращений с начала года (имя вида
`nr-01.01.26-03.06.2026.xlsx`). На сервере хранится только последний такой
файл — вся аналитика (вчера, ЦУР-неделя чт→ср, месяц, квартал со сравнением
с предыдущими периодами) считается из него на лету.

На странице аналитики также есть блоки **«Исполнение»** (структура статусов,
доля закрытых, возвраты и отложенные с динамикой по периодам) и
**«Горячие точки»** (рейтинг адресов/улиц по категориям). Срок «в срок /
просрочено» не считается — в выгрузке нет даты закрытия.

**Живой сайт:** https://aggasyas.github.io/cur-analytics/

## Что внутри

| Файл | Назначение |
|------|------------|
| `parse_cur.py` | Разбор Excel-выгрузки → метрики, статусы исполнения, горячие точки |
| `cur_periods.py` | Нарезка накопительного файла по дням и периодам (неделя/месяц/квартал) |
| `metrics_cur.py` | Извлечение метрик, история, сравнение день-к-дню |
| `render_cur.py` | HTML-сводка дня (KPI, критичные темы, источники, исполнители) |
| `render_cur_analytics.py` | Страница аналитики: периоды, исполнение, горячие точки, тренды |
| `render_cur_index.py` | Индекс с навигацией год → месяц → день |
| `build_all_cur.py` | Сборщик всего сайта из одного накопительного файла |
| `docs/` | Готовый сайт (его и раздаёт GitHub Pages) |
| `bot/` | Telegram-бот ЦУР + инструкция по установке |

## Ручная сборка (без бота)

```bash
python build_all_cur.py "nr-01.01.26-03.06.2026.xlsx"
```

Сайт пересоберётся в `docs/` целиком из накопительного файла (страницы за все
дни + аналитика + индекс). История на сервере не нужна — источник правды сам
файл. Повторный запуск перезаписывает сайт без дублей.

## Боты

Есть два бота, работают **параллельно** на одном сервере — кидаете рабочий
файл в любой из них, аналитика пересобирается и публикуется, в ответ
приходят ссылки на сводку / аналитику / индекс.

| Бот | Файл | Инструкция |
|-----|------|-----------|
| Telegram | `bot/cur_bot.py` | [`bot/INSTRUKCIYA.md`](bot/INSTRUKCIYA.md) |
| MAX | `bot/cur_max_bot.py` | [`bot/INSTRUKCIYA_MAX.md`](bot/INSTRUKCIYA_MAX.md) |

Общий API-клиент MAX — `bot/max_core.py`. Конфиг MAX-бота отдельный:
`bot/.env.max` (пример — `bot/.env.max.example`), systemd-юнит —
`bot/cur-max-bot.service`. Telegram и MAX не мешают друг другу: у каждого
свой процесс и свой `.env`, оба пересобирают один и тот же сайт.

## Анонимность

На страницах НЕ публикуются тексты обращений, почта и адреса заявителей —
только агрегированные цифры, направления и подтемы. Репозиторий публичный,
сайт безопасно показывать.
